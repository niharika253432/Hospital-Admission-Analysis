HOSPITAL ADMISSION ANALYSIS - WINDOWS EASY RUN

1) Install Python from https://www.python.org/downloads/ (during setup tick Add Python to PATH).
2) Extract this project ZIP.
3) Open the extracted folder in VS Code.
4) In VS Code choose Terminal > New Terminal.
5) Run these commands:
   python -m pip install -r requirements.txt
   python app.py
6) Open your browser and go to:
   http://127.0.0.1:5000

To stop the server, click the terminal and press Ctrl+C.

This is a Windows-friendly demonstration built from synthetic admission records.
It reproduces report-style analyses using Python/Flask and charts, not a live Hadoop/Hive cluster.
Risk categories are transparent educational scores, not validated medical predictions.
